📌 خلاصه‌ی پروژه Control System Manager
═══════════════════════════════════════════════════════════

🎯 هدف: برنامه طراحی سیستم کنترل BMS با Python/Tkinter

📁 مسیر پروژه:
D:\01-Projects\Control System Design\control_system_manager

🛠️ تکنولوژی‌ها:
- Python 3.14
- Tkinter (GUI)
- SQLite (Database)
- reportlab + python-docx (خروجی)
- openai (AI)
- arabic-reshaper + python-bidi (PDF فارسی)

═══════════════════════════════════════════════════════════
✅ کارهای انجام‌شده (فاز ۱-۴)
═══════════════════════════════════════════════════════════

۱. Learning Engine — یادگیری از ۸ پروژه، ۴۲۵ دستگاه
۲. Local Proposal Generator — تولید پروپوزال با تصاویر
۳. DeepSeek Client + Config Manager — API Key در config.json
۴. Section Detector — تشخیص ۱۱/۱۱ نوع سکشن
۵. Query Engine — ۱۰/۱۰ کوئری موفق
۶. Steam Kv Calculator (IEC 60534-2-1)
۷. VFS 2 Valve — از کاتالوگ Danfoss
۸. Valve Dialog — کارت Steam + Choked Flow
۹. PDF فارسی — RTL کامل
۱۰. Cable Tag Sanitization — فقط ASCII
۱۱. EXE نهایی — ~۶۵ مگابایت
